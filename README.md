# Бот-ассистент курса

Telegram-бот для студентов курса подготовки инструкторов дыхательных техник.
Отвечает на вопросы по структуре курса, урокам и подготовке к экзамену —
на основе базы знаний в `content/knowledge-base/`, без выдумывания фактов.

## Как это работает

1. Материалы курса (структура, уроки, экзаменационные билеты, FAQ) лежат как
   markdown-файлы в `content/knowledge-base/`. Каждый заголовок `##` — отдельный
   фрагмент, который бот может найти и процитировать.
2. При вопросе бот ищет 5 наиболее релевантных фрагментов (`src/rag/knowledgeBase.js`)
   и передаёт их вместе с вопросом в Claude (`src/rag/answer.js`), который отвечает
   строго на основе этого контекста.
3. Telegram-бот (`src/bot/bot.js`, библиотека grammY) принимает сообщения и
   пересылает их в этот пайплайн.

Почему не автосинхронизация из GetCourse: API GetCourse (getcourse.ru/help/api)
рассчитан на CRM-объекты — пользователей, заказы, прогресс по урокам, а не на выгрузку
полного текста уроков и билетов. Поэтому наполнение базы знаний — ручной процесс:
скопировать текст урока/билета из админки в markdown-файл. `src/getcourse/client.js` —
заготовка на будущее, если понадобится проверять студента по потоку или его прогресс.

## Наполнение базы знаний

Отредактируйте файлы в `content/knowledge-base/` (сейчас там шаблоны-заглушки):

- `course-structure.md` — модули, уроки, формат обучения
- `exam-prep.md` — формат экзамена, билеты (каждый билет — свой `##`)
- `faq.md` — частые вопросы, включая технику безопасности практики

Можно добавлять новые `.md` файлы — они подхватятся автоматически.

## Запуск локально

```bash
npm install
cp .env.example .env   # и заполнить ключи
npm start
```

Нужные ключи в `.env`:

- `TELEGRAM_BOT_TOKEN` — от @BotFather в Telegram
- `ANTHROPIC_API_KEY` — из console.anthropic.com
- `GETCOURSE_ACCOUNT` / `GETCOURSE_API_KEY` — опционально, только если будете
  использовать `src/getcourse/client.js`

## Деплой (Railway)

1. Залить репозиторий на GitHub.
2. В Railway: New Project -> Deploy from GitHub repo.
3. В Variables прописать те же переменные, что в `.env`.
4. Start command: `npm start` (определится автоматически из `package.json`).

Бот работает через long polling (`bot.start()`), поэтому вебхук и публичный URL
не нужны — достаточно, чтобы процесс был постоянно запущен.
